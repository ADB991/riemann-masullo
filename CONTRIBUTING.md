# Contributing

The workflow, the rules for Lean code and how to hand in work are in [`AGENTS.md`](AGENTS.md); they
are the same for people and for coding agents. Role prompts are in [`prompts/`](prompts/README.md).

Pick an open issue labelled `proof` or `section` that is not labelled `claimed`, comment that you
are taking it, and open a pull request against `main`.
